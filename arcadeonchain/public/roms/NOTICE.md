# What is in the cabinets, and on whose terms

Three games are redistributed here. Each one carries an explicit licence from its
author that permits it; none of them is here on an assumption. This file ships
with the bundle because two of these licences require it to.

The credit bar in the app names the author, the licence and the source for
whichever cabinet you are standing at. This is the same information, in one
place, for someone holding the files rather than playing them.

---

## Jeznes — `jezzball.nes`

- **Author:** boingoing
- **Licence:** MIT
- **Source:** https://github.com/boingoing/jeznes

MIT requires that its notice accompany the software. Full text:
https://github.com/boingoing/jeznes/blob/main/LICENSE

A JezzBall-like for the NES. It is *not* JezzBall, which is Microsoft's; the
author's name for it is Jeznes, and that is the name the cabinet uses.

## Tobu Tobu Girl Deluxe — `tobutobugirldeluxe.gbc`

- **Author:** Tangram Games (SimonLarsen)
- **Licence:** MIT for the code, **CC BY 4.0 for the assets**
- **Source:** https://github.com/SimonLarsen/tobutobugirl-dx

CC BY 4.0 requires attribution, which the cabinet gives on screen and this file
repeats. Licence text: https://creativecommons.org/licenses/by/4.0/

## Geometrix — `geometrix.gbc`

- **Author:** AntonioND (Antonio Niño Díaz)
- **Licence:** GPL-3.0-or-later
- **Source:** https://github.com/AntonioND/geometrix

The GPL requires that the corresponding source be offered to anyone who receives
the binary. The repository above is that offer, and it is linked from the
cabinet's credit bar while the game is running.

---

## What is not here

Nothing is in a cabinet on the grounds that it is old, abandoned, or hard to buy.
An empty cabinet is shown as empty. If you are the author of something here and
want it taken out, that is enough of a reason — say so and it goes.
